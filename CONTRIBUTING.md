# Contributing

Thank you for considering a contribution to KH Reference Integrity.

## Before opening a pull request
1. Open an issue describing the problem or proposed enhancement.
2. Keep checks transparent and explainable.
3. Do not label a source as fake or fabricated based only on missing metadata.
4. Add or update tests for every behavior change.
5. Preserve Arabic and English text handling.

## Development
- Python 3.10+
- Runtime dependencies: none
- Run tests: `python -m unittest discover -s tests -v`

## Pull requests
Include the motivation, behavior change, test evidence, and known limitations.
Do not include private manuscripts, personal data, or copyrighted datasets without permission.
